# LogistiCore

**Build a logistics company, manage your fleet, and grow a nationwide transport network across Türkiye.**

LogistiCore is a mobile logistics management simulation built with React Native and Expo. It combines fleet planning, delivery operations, company growth, warehouse systems, driver management, contracts, and an online global economy into a single management game.

> Developed as a production mobile game for Android and iOS.

## Highlights

- **Fleet management** — manage trucks, trailers, drivers, fuel, condition, and operational state.
- **Delivery operations** — move cargo between cities while balancing time, fuel, cost, and delivery risk.
- **Contracts & progression** — accept increasingly demanding jobs and grow the company over time.
- **Warehouses & stock transfers** — manage logistics infrastructure beyond individual deliveries.
- **Global economy** — shared market snapshots are generated by a trusted Firebase backend rather than by clients.
- **Vehicle marketplace** — backend foundations for player-to-player vehicle trading with production gating and migration tooling.
- **Leaderboards & progression systems** — competitive and long-term progression features are developed behind production-safe feature flags.
- **Offline progression & recovery** — gameplay systems include save recovery, lifecycle persistence, and offline delivery progression safeguards.
- **Cross-platform production checks** — dedicated Android/iOS validation and regression scripts protect release builds.

## Architecture

The client is designed around a local-first gameplay loop while trusted online systems remain server-authoritative where consistency matters.

### Global economy backend

Canonical market snapshots are not generated by production clients. A scheduled backend worker owns the shared economy flow:

- `backend/src/index.ts` — scheduled worker entry point
- `backend/src/globalEconomyWorker.ts` — Firestore transaction and idempotency logic
- `backend/src/globalEconomyGenerator.ts` — canonical snapshot generation
- `backend/scripts/syncCanonicalInputs.ts` — synchronizes client catalog/config contracts before builds

The backend includes emulator coverage for concurrency, retry/rollback behavior, Firestore rules, history queries, configuration mismatch, and stale-cache scenarios.

## Reliability & testing

LogistiCore includes a broad regression suite covering areas such as:

- offline economy and delivery settlement
- save checksum and save recovery
- marketplace purchase/reconciliation flows
- leaderboards and eligibility
- delivery incidents and random events
- warehouse upgrades and stock transfers
- fleet upgrades
- account deletion and cloud-save flows
- iOS layout, Firebase, authentication, and ad configuration
- map tracking and truck-route integrity
- performance and cold-start regressions

Run the primary verification commands locally:

```bash
npm install
npm --prefix backend install
npm run typecheck
npm run firebase:emulators:test
npm --prefix backend run typecheck
npx expo export --platform android
```

For the full project regression suite:

```bash
npm run verify
```

## Production deployment

Before deploying the global economy backend, complete the [production checklist](docs/production-global-economy-checklist.md).

```bash
firebase use logisticore-53ab4
firebase deploy --only firestore:rules
firebase deploy --only firestore:indexes
firebase deploy --only functions
```

Production deployment requires the appropriate Firebase project permissions, billing plan, and Google Cloud APIs.
