# Dashboard PNG Assets

Place the following PNG files in this directory before enabling `require()` exports in
`src/assets/dashboardAssets.ts`.

| File | Purpose |
|------|---------|
| `company-emblem-gold.png` | Company hero emblem |
| `dashboard-port-background.png` | Dashboard port / hero background |
| `next-action-truck-route.png` | Next-action CTA decoration |
| `daily-support-ticket.png` | Daily ops support card icon |
| `dashboard-grid-overlay.png` | Subtle grid overlay texture |

All filenames are case-sensitive. Do not commit zip archives or temporary extraction folders here.
